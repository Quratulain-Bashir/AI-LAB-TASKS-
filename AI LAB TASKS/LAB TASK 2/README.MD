# Mini FizzBuzz Project

    This is a simple interactive FizzBuzz game implemented in Python.

## How It Works

    - The program asks you to enter a maximum number (default is 100).
    - For each number from 1 up to the maximum, you must type:
        - "FizzBuzz" if the number is divisible by both 3 and 5,
        - "Fizz" if divisible by 3 only,
        - "Buzz" if divisible by 5 only,
        - The number itself otherwise.
    - Type "q" or "quit" to exit early.
    - Your score and number of attempts are displayed at the end.
